# Update: the public site is served in English and Brazilian Portuguese, with a language toggle

## Outcome

The landing page and the docs page (`web/`) now exist in English at `/` and `/docs/` (unchanged) and in Brazilian Portuguese at `/pt-br/` and `/pt-br/docs/`. An `EN | PT-BR` toggle in the nav, the mobile menu and the docs sidebar switches language and keeps the current `#anchor`. Every page sets `lang`, `canonical`, `hreflang` (`en`, `pt-BR`, `x-default`) and `og:locale`. Ticket 0069B. Site only: no version bump, nothing shipped to installed projects.

## Changes

- **Routing (F1).** Astro's built-in i18n with `defaultLocale: "en"` and `prefixDefaultLocale: false`. URLs end in `/`.
- **Strings modules (F2).** `web/src/i18n/en.ts` and `pt-br.ts` hold all site copy; `index.ts` gives `useT`, `localeHref` and `alternateUrls`. Build-time guards fail `npm --prefix web run build` when a PT key is missing, extra or empty, when a `name` differs, or when a PT value equals its EN value outside `SAME_IN_BOTH`.
- **Layout and toggle (F3, F4).** Locale-aware `Layout.astro`; new `LanguageToggle.astro` (plain links, JS only adds the hash and remembers the choice, never redirects); `pt-br/index.astro` and `pt-br/docs.astro` render the shared page files.
- **Copy moved (F5, F6, F8 to F10).** `CommandLine`, the landing page and the whole docs page, including the strings their inline scripts print, read from the modules. The docs commands grid is `docs.commands.groups`, rendered by one loop. Command, skill, agent and plugin names, paths, the Mermaid graph and the ecosystem map stay English.
- **Tests (F7).** The five cli tests that read docs copy now read `docs.astro` followed by `en.ts`. `scripts/tests/web-site.test.cjs` gains the i18n assertions.
- **Doc sync (F11 to F14).** `/add-framework--sync` and the two web analyzers target the strings modules; every copy edit is an `en.ts` object plus a `pt-br.ts` object, and the coordinator applies neither half of an unpaired report. `AGENTS.md` maps the new files.

## Action for installed projects

None. The site ships in no package.
