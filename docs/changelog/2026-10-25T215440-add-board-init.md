# Add: enabling the board feature creates the board

## Outcome

Turning the `board` feature on now creates a working board: `.codeadd/board.json`, the orphan `board` branch on `origin` and the clone under `~/.codeadd/<project-key>/board/`. One shipped script, `board-init.cjs`, does it, and `codeadd features enable board`, `codeadd modify --enable-feature board`, `codeadd install --enable-feature board` and `/add-setup` all call it. Only `.codeadd/board.json` is staged on the code side, and nothing on a code branch is committed or pushed. A project that already has a board is left as it was (`BOARD=ready`). Every failure (no git, no origin, empty remote, push refused) is one warning line and the enable still succeeds. Ticket 0070B.

## Changes

- **Script (F1).** `framwork/.codeadd/scripts/board-init.cjs` acts on the resolver state. The root commit is `Create the board` with `Migrated-From`, `Backlog-Blob: none` and `Definitions-Blob: none`, so `migrate-board.cjs` still recognises it. The base branch is origin/HEAD, then main, then master; none means `ERROR=no-base-branch` and nothing is pushed. The fetch prunes, and fetch and push carry git's network timeout.
- **Inventory (F2).** `AGENTS.md` lists the script.
- **Messages (F3).** `backlog-commit.cjs` and `backlog-cli.cjs` point at `board-init.cjs` and the README Board section instead of the framework maintainer.
- **CLI (F4).** `cli/src/board-init.js` runs the script from the four enable sites, in project scope, when `board.json` is absent.
- **/add-setup (F5).** `board` is offered like any item and recorded `enabled` or `failed` from `BOARD=` / `ERROR=`. `unavailable` stays in `add--settings` as a legacy value, read and never written.
- **Texts (F6).** `add--backlog`, `add--ecosystem`, `agent-mode/board-management.md` and the board app's error panel. A guard test fails when shipped text says "framework maintainer".
- **Docs (F7).** README "New project" paragraph and a `CHANGELOG.md` entry.

## Action for installed projects

None on update. Enabling `board` on a project needs an `origin` with its main branch pushed. Then commit the staged `.codeadd/board.json`. A token embedded in the `origin` URL is written to `board.json`.
