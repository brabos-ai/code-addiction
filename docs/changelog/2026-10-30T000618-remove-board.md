# Remove: the board feature and everything built around it

## Outcome

The framework no longer ships a backlog board. The `board` feature, its injected text, the backlog scripts, the board app and the pipeline's ticket steps are gone. Feature folders are named `<id>-<slug>` and the id allocator counts feature folders only. A consumer's `.codeadd/board.json`, `board` branch and clone are never touched.

## Changes

- **Guard (F1).** `cli/tests/board-removed.test.js` pins five end-state assertions; every skip is gone after F8.
- **Fragments and slots (F2).** `fragments/board/` and its 24 slots are removed from six commands; the injection map falls by 25 members.
- **CLI (F3, F4).** `board` leaves `FEATURES`, install, modify, gitignore and `board-init`. Migration `0006-retire-board` drops the flag on update and notes it once; the retired `0004` id is tolerated.
- **Scripts (F5, F6).** `backlog-cli`, `backlog-commit`, `backlog-board`, the core modules and the `add--backlog` skill are deleted; `status.cjs` prints no `BOARD=`. `backlog-id.cjs` becomes `feature-id.cjs`, counts folders only and refuses `B` for new ids while still reading old ones.
- **Skills and agent mode (F7, F8).** The doc schemas drop `ticket:` (a legacy value stays valid). `board-management.md` and the "Mirror the board" section go; the agent-mode result block has no `ticket` field.
- **Report text (F9).** `add-done` names the feature folder `<id>-<slug>`; a test pins that across seven commands and the schema.
- **Docs (F10, F14, F15).** `cli/README.md`, `README.md`, `AGENTS.md`, `ecosystem.md`, both site locales and `CHANGELOG.md` drop the board and say where the data stays.
- **Internal tooling (F11, F12).** `board/`, `build-board-runtime.js`, `board-files-guard.cjs`, the `board` and `board-e2e` test stages and CI jobs, and this repository's own `.codeadd/board.json` are removed; `setup` is the workbench build alone.
- **Workbench (F13).** `add-framework--backlog` is deleted; brainstorm, plan, build, done and release lose every ticket step and the `--ticket` flag; the workbench result block has no `ticket` field.
- **Review fixes.** Cli tests that read the removed command, the root `.gitignore` and one list in the brainstorm skill follow the end state.

## Action for installed projects

`codeadd update` runs migration `0006-retire-board`. It removes the `board` flag from the manifest and leaves `.codeadd/board.json`, the `board` branch and the clone under `~/.codeadd` as they are.
