## Decided
- Port objective-as-anchor, pipeline-chains and brainstorm conduct to the product layer — the internal layer already proved each one
- `add.brainstorm` drafts the objective first and the user corrects it — asking cold hands the work back
- `add.brainstorm` follows the section checklist, names outside practice (WebSearch kept), repository wins on conflict
- `add.brainstorm` always writes its document on `architectural`, self-reviews it, no agent dispatch — keeps the ceremony rebalance's cut
- Three-option approval (confirm / automatic / keep discussing) replaces the inline `about.md` offer — `/add.new` owns id, directory and gate
- Automatic chain: `add.brainstorm → add.new → add.plan → add.build → add.review`, loop capped at two reviews, then `add.build` STEP 17 PR question with remaining findings shown — user's cap; superpowers shape
- Commands hand off to each other; review round counted from the delivery's `review-NNN.md` files — disk is the counter
- Epic split in automatic mode asks: continue automatic (all pending SFs, PR question at end) or semi-automatic (stop between SFs) — deciding stop
- Each SF states how it serves the feature objective; one that cannot STOPs with the two readings
- `about.md` Decisions gains `Serves`; `plan.md` gains `## Objective` copied, `> **Delivery:**` header, preview before writing
- `add-plan-review` + `plan-reviewer-agent` gain `Objective fit` as ninth dimension
- New skill `add-delivery-mode` owns deciding vs confirming — no product mirror of `add-plan-authoring` exists
- QA "confirm before fixing" is confirming; manual routes, missing Fix Routing and TDD 3-strike are deciding; `add.qa-setup` stays outside the chain
- `add.build` owns "The Checkpoint Sequence" moved from `add.plan-to-ready` (converge-gates, commit, tag, `epic.md` checkpoint cell); tag name unchanged so `status.sh` and `done.sh` need no change
- Remove `add.plan-to-ready` and every reference — the chain replaces it
- One design document, not an umbrella — the three themes edit the same commands; the planner phases it
