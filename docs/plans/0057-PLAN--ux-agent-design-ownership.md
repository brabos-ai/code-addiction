## Context

Three of the four QA chain breaks share one root cause: the design contract is optional, and when it exists it is written where the judge does not look. This plan makes `design.md` production unconditional for screen-bearing features (owned by `add.plan`), written at the scope `add.qa` reads (`SF_DIR` for epics, `FEATURE_DIR` otherwise), splits the spec author into two sequential agents, promotes `@ux-agent` to adversarial critic, inverts `screens.json` ownership to `add.plan` STEP 10.0, and activates the already-wired `add.build` consumption path (`HAS_DESIGN`).
